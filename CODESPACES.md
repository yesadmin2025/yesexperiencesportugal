# 🌐 GitHub Codespaces Setup

GitHub Codespaces lets you code directly in your browser without installing anything locally!

## ✨ What Codespaces Provides

- ✅ Full development environment in your browser
- ✅ Pre-configured Node.js and npm
- ✅ VS Code editor online
- ✅ All dependencies pre-installed
- ✅ Port 3000 automatically forwarded for preview
- ✅ ESLint and Prettier pre-configured
- ✅ Automatic setup on creation

## 🚀 Getting Started with Codespaces

### Step 1: Open Your Repository

Go to: https://github.com/yesadmin2025/yesexperiencesportugal

### Step 2: Click "Code" Button

Click the green **Code** button at the top of the repository.

### Step 3: Open Codespace

1. Click the **Codespaces** tab
2. Click **Create codespace on main**
3. Wait for the environment to build (about 2-3 minutes)

### Step 4: VS Code Opens in Your Browser

Once ready, you'll see VS Code with your project fully loaded!

## 💻 What's Already Done

When your Codespace starts:
- ✅ All dependencies are installed

## 🎯 Start Developing

Once in Codespace, open the terminal and run:

```bash
npm run dev
```

You'll see:
```
VITE v4.3.0  ready in 234 ms

➜  Local:   http://localhost:3000/
➜  press h to show help
```

Click the link or look for a popup to preview your app!

---

## 📂 File Structure in Codespace

```
src/
├── main.tsx        ← React entry point
├── App.tsx         ← Main component (edit this!)
├── App.css         ← Component styles
├── App.test.tsx    ← Tests
└── index.css       ← Global styles
```

---

## 🔧 Available Commands in Codespace

In the terminal, you can run:

```bash
npm run dev          # Start dev server
npm run build        # Build for production
npm run test         # Run tests
npm run lint         # Check code quality
npm run format       # Format code
npm run type-check   # Check TypeScript
```

## 💡 Tips for Codespaces

### Auto-Save
Files auto-save by default - no need to manually save!

### Hot Reload
Make changes and see them instantly in the browser preview

### Terminal
Click the terminal at the bottom or press `` Ctrl+` ``

### Preview
Port 3000 should auto-forward. If you see a notification, click it!

### Extensions
VS Code extensions are pre-installed:
- ESLint (code quality)
- Prettier (code formatting)
- TypeScript support

## 📊 Codespace Specs

- **Memory**: 4GB
- **Storage**: 32GB
- **CPU**: Generous (shared)
- **Duration**: Free for 60 hours/month for personal accounts
- **Cost**: Free within limits!

---

## ❌ When to Use Codespaces vs Local

### Use Codespaces When:
- ✅ You don't have Node.js installed
- ✅ You want to start immediately
- ✅ You're using a Chromebook or tablet
- ✅ You want to avoid local setup

### Use Local When:
- ✅ You want better performance
- ✅ You're working on large projects
- ✅ You need offline access
